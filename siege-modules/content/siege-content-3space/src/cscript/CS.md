### CS File Format

CS is short for CScript and is the primary scripting file format most late 90s 3Space games and all Torque engine games.

CScript has several dialects, with two existing in parallel: there was the SCS dialect in Red Baron 2/3D for its dedicated server component.

Then, for King's Quest Mask of Eternity, Ski Racing and Starsiege ATR a different dialect existed.

The difference between the two dialects was syntax, with the SCS dialect resembling JavaScript and the other looking like linear shell code.

The SCS dialect became the standard thereafter and was used in Starsiege and Starsiege: Tribes.

Once Tribes 2 arrived, the features were greatly expanded and it became a fully fledged object-oriented programming language used to control most of the game's logic.
