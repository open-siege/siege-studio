#### Third Generation (3Space 3.0 and 3.5)

The third generation of Dynamix's 3Space game technology was designed to make it easier to create content from within the game and to externalise game logic into script files.

Many of the ideas present in this generation would be expanded upon with the [Torque](/siege-modules/extension/siege-extension-3space/src/torque.md) engine.
